原子習慣（上）

這篇文章我們來統整【原子習慣】中的核心知識，並解惑那些關於養成習慣的錯誤理解。

一、「進步」也許不是你想的那樣​

大多數人經常對「進步」這件事有誤解，認為只要付出時間、心力...就可以換取等量的進步。

但實際情形是，如果我們以時間為橫軸，成果為縱軸，畫出一條「進步曲線」，它並不是一條沿 45 度角向上的直線，而是一條斜率漸增的曲線。


Source：thunknotes.com

圖中的黃線呈現了進步真正的樣子。

所以，在維持習慣的初期沒辦法收穫立即「可見」的成長，這無疑是一件令人沮喪並引誘人放棄的事，也正是能堅持到最後的人這麼少的原因。

不過，一旦習慣堅持得夠久，便能在某一刻收穫跳躍式的成長。以煮水為例，把水從三十度煮到四十度，水面看起來沒什麼變化，但並不是沒有成果。當你把水從九十度煮到一百度，水則在「瞬間」之間滾了，這就是所謂看起來「跳躍式」的成長。

旁人看似「突然」發生的成功，只有自己清楚你煮了多久。

二、別與天性（懶惰）作對​

人類的大腦會自然地追求最低耗能的狀態，傾向選擇當下看起來最簡單的事情做。

然而大部分有價值的事做起來都很困難。所以我們並不是要單靠「意志力」和大腦對抗，這不可行也不長久。我們需要做的是設計一個流程或是一個環境讓我們用最少的力氣維持習慣。

啟動習慣本身就不簡單，不要再讓它變得更困難。

  • 假設你想要練鋼琴，但每次要開始前都要把鋼琴上的一堆雜物全部搬走才能開始彈，你覺得你會常彈鋼琴嗎？
  • 或是你想靠健身維持體態，但卻選了一個跟下班回家一點都不順路的健身房，你還會常去健身嗎？

答案是顯而易見的。

所以別再用「意志力」催眠自己有辦法自律了，我們大多會敗給自己的惰性（大家應該都頗有經驗吧？）。反而應該設計一個流程，讓啟動門檻「越簡單越好」。

我們在這篇文章建立好一些關於養成習慣的正確觀念後，原子習慣（下）中將會討論具體而言，如何用正確的方式養成習慣，推薦大家去看看！
